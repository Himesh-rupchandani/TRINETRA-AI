# TRINETRA AI backend — core runtime dependencies
# =================================================
# Everything needed to serve the API: registry, events, watchlist, alerts,
# vehicle investigation + GIS routes, stats, bandwidth/speed/insights engines,
# BSA reports, SSE realtime. Deliberately WITHOUT the computer-vision stack so
# this set can run where a 2 GB torch install cannot: serverless functions
# (Vercel/Cloud Run), CI containers, or a machine that only needs the data API.
#
# Frame decoding, live MJPEG, vehicle detection and ANPR need the extras in
# requirements-ml.txt. app/core/vision.py resolves both lazily, so the app
# imports cleanly either way and the CV routes answer 503 with an explanation
# instead of crashing at boot.
#
#   Full local/Docker CV deployment:  pip install -r requirements-ml.txt
#   API-only / serverless:            pip install -r requirements.txt
