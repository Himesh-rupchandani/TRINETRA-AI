   here. Live-feed verification must run from the hackathon network (`cv-engine/scripts/check_catalogue.py`
   then `run_pipeline.py --mode live`). Everything else was verified for real.
2. Department/zone/uptime fields are intentionally empty in live mode (backend/Sentinel do not provide
   them) — the UI shows `—` rather than fabricated values.
3. `cameraService.stream()` builds the ticket from the same-origin WHEP proxy path; a future
   hardened deployment can move this behind an authenticated backend ticket endpoint.
